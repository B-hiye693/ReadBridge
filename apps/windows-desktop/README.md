# 阅桥 Windows 桌面客户端

这是独立的 WPF 客户端，支持全局快捷键读取 UI Automation 文字选区、屏幕框选 OCR、手动粘贴、文件全文导入、简单解释、一键易读和可选音色朗读。截图与原文默认只在当前会话内存中保留；OCR 截图不会上传或落盘。

## 直接运行

日常使用请从根目录 `启动阅桥\一键启动阅桥.cmd` 进入。当前桌面产物位于 `artifacts\ReadBridge-Desktop-win-x64-v18\ReadBridge.exe`。这是 `win-x64` 自包含文件夹，目标电脑不必安装 .NET。请保留整个目录，不要只复制 EXE。英文 OCR 模型已随程序发布，不依赖 Windows Update；中文 OCR 仍使用 Windows 简体中文语言能力。后端仍需在另一个终端启动：

```powershell
cd E:\AYQ\easyread
.\.venv\Scripts\python.exe -m uvicorn server.main:app --app-dir apps/api --host 127.0.0.1 --port 8000
```

后端离线时，取文、OCR、编辑预览和 Windows 系统朗读仍可用；解释、一键易读会给出明确提示。后端配置为云端 Provider 时，确认后的文本会继续发送给对应模型服务；API Key 仍只由后端 `.env` 管理。

## 操作

- 默认全局快捷键为 `Ctrl+Alt+R`。先在目标应用中选中文字，再按快捷键。
- `Ctrl+Alt+E` 会读取当前选区并立即生成简单解释。输入框为空时也可先点“简单解释”，再在 4 秒内到目标应用选择文字。
- “框选识字”覆盖全部显示器；拖动选择当前可见区域，`Esc` 取消。结果明确标记为“屏幕框选 OCR（仅当前可见区域）”。
- “粘贴”提供不支持 UI Automation 时的稳定后备路径。
- 可点击“打开文件”或把 TXT、Markdown、HTML、DOCX、文字型 PDF 拖进窗口。长文由桌面端按段完整送入易读流程；扫描型 PDF 需改用框选识字。
- 成功读取的文件会自动保存到本机文件库（原文件副本和提取文本）。同内容文件自动去重；点击“文件库”可搜索、重新打开或删除。
- 输出语言默认“跟随原文”，也可强制输出中文或 English。音色列表来自后端，后端语音不可用时自动回退 Windows 系统语音。
- 关闭按钮只隐藏到托盘；从托盘菜单退出才会结束进程。隐藏、重新捕获、修改文本或取消时，会取消旧请求并停止旧音频。
- `Ctrl++` / `Ctrl+-` 调整字号，`Esc` 取消当前操作。设置页可更改后端地址、快捷键和默认置顶。

## 构建

安装 .NET 10 SDK 后双击 `apps\windows-desktop\build.cmd`，或运行：

```powershell
.\apps\windows-desktop\build.ps1
```

产物位于 `artifacts\ReadBridge-Desktop-win-x64-v18\ReadBridge.exe`。

## 支持边界与验收记录

| 场景 | 当前状态 |
| --- | --- |
| 记事本、支持 TextPattern 的标准文本控件 | 已实现；需在交互式桌面实测 |
| Chrome / Edge 普通网页文本 | 依赖浏览器无障碍树；需在交互式桌面实测 |
| Word / PDF 阅读器 | 取决于应用是否暴露 TextPattern；失败时使用 OCR / 粘贴 |
| 密码框、管理员权限更高的窗口、受保护内容 | 主动拒绝或提示权限边界 |
| 多显示器与混合缩放 | Per-Monitor-V2 + 虚拟屏物理坐标实现；需用真实混合缩放显示器实测 |
| OCR 中英数字图片、语言包缺失、空结果、取消 | 已实现；真实图片与语言包组合需交互式桌面实测 |
| 后端离线、快捷键冲突、无选区、旧请求/旧音频 | 已实现错误提示与代次取消；自动构建可验证，交互行为需实测 |

本环境只能完成编译、API 和非交互回归，不能诚实声称已操作真实记事本、浏览器、Word 或多显示器。测试这些场景时应记录具体应用版本、权限级别、显示器缩放与结果。
